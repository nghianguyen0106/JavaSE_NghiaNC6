# 6. Scalability, Availability & Observability
### **Cần học gì**

- Scalability: horizontal/vertical.
- Availability.
- SLI, SLO, SLA.
- Redundancy.
- Health check.
- Failover.
- Rate limiting.
- Timeout/retry/circuit breaker.
- Logging, metrics, tracing.
- Correlation ID.
- Alerting.
- Error budget ở mức khái niệm.

### **Cần hiểu đến mức nào**

Ví dụ NFR:

`Payroll Run API:
- Availability: 99.9%.
- p95 create payroll request: < 500ms.
- Payroll calculation async completion: < 30 minutes.
- Duplicate payroll run: 0 tolerated.
- Audit event loss: 0 tolerated.`

Mentee cần phân biệt:

`Scalability:
- Tăng traffic thì xử lý thêm instance/partition/cache/queue được không?

Availability:
- Một instance/database/region lỗi, service còn phục vụ được không?

Observability:
- Khi chậm/lỗi, team có biết lỗi ở đâu và tại sao không?`
