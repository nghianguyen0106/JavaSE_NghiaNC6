3. Event-Driven Architecture: Events, Commands & Message Broker### **Cần học gì**

- Command.
- Domain event.
- Integration event.
- Message broker.
- Producer/consumer.
- At-least-once delivery.
- Idempotent consumer.
- Ordering.
- Retry, DLQ.
- Event schema evolution.
- Outbox pattern ở mức khái niệm.

### **Cần hiểu đến mức nào**

Phân biệt:
`Command:
"RunPayroll" / "ReserveInventory"
→ yêu cầu một service thực hiện hành động.
→ thường có target rõ ràng.

Event:
"PayrollCompleted" / "EmployeeSalaryChanged"
→ một sự kiện đã xảy ra.
→ có thể có nhiều consumer.

Message:
Khái niệm transport chung; có thể chứa command, event hoặc data.`

Ví dụ:

`Payroll Service
    ├── xử lý RunPayroll command
    └── publish PayrollCompleted event

Notification Service
    └── consume PayrollCompleted → gửi email

Reporting Service
    └── consume PayrollCompleted → cập nhật dashboard

Audit Service
    └── consume PayrollCompleted → lưu audit trail`
