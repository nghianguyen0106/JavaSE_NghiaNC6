# 5. Caching Strategies & Cache Invalidation

### **Cần học gì**

- Cache-aside.
- Write-through.
- Write-behind/write-back ở mức khái niệm.
- TTL.
- Cache invalidation.
- Cache stampede.
- Cache penetration.
- Stale data.
- Cache key design.
- Distributed cache.
- Cache metrics.

### **Cần hiểu đến mức nào**

#### **Cache-aside**

`Read:
Application → Cache
  ├─ hit  → trả data
  └─ miss → đọc DB → ghi Cache → trả data

Write:
Application → DB
Application → invalidate/update cache`

#### **Write-through**

`Application → Cache layer
Cache layer → DB`

Mentee cần biết cache không chỉ là “thêm Redis cho nhanh”.

Phải trả lời:

`- Cache data nào?
- Cache key là gì?
- TTL bao lâu?
- Khi data update thì invalidation thế nào?
- Nếu cache miss hàng loạt thì DB chịu được không?
- Dữ liệu stale bao lâu chấp nhận được?`
