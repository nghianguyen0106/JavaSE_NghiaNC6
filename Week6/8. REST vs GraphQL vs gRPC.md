# 8. REST vs GraphQL vs gRPC
### **Cần học gì**

- REST resource-oriented API.
- REST pagination/filtering/versioning/error model.
- GraphQL query flexibility.
- GraphQL N+1 risk, query complexity, authorization.
- gRPC/protobuf, service-to-service communication.
- Streaming.
- External API vs internal API trade-off.

### **Cần hiểu đến mức nào**

| **Tiêu chí** | **REST** | **GraphQL** | **gRPC** |
| --- | --- | --- | --- |
| Public web/mobile API | Phổ biến, dễ cache/debug | Hợp UI cần dữ liệu linh hoạt | Thường không ưu tiên cho browser public API |
| Internal service-to-service | Có thể dùng | Ít phổ biến hơn | Rất phù hợp khi cần typed contract/efficiency |
| Streaming | Có giới hạn | Subscription có thể dùng | Mạnh |
| Over/under-fetching | Có thể xảy ra | Giảm được | Theo contract RPC |
| Caching HTTP | Dễ hơn | Phức tạp hơn | Khác mô hình HTTP cache |
