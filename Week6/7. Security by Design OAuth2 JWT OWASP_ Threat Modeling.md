# 7. Security by Design: OAuth2, JWT, OWASP & Threat Modeling
### **Cần học gì**

- Authentication vs authorization.
- OAuth 2.0 roles.
- Access token vs refresh token.
- JWT: claims, signature, expiry.
- Token audience, issuer, scope.
- Secret/key management.
- OWASP Top 10.
- Threat modeling.
- STRIDE ở mức khái niệm.
- Secure-by-default API design.

OAuth 2.0 định nghĩa các vai trò resource owner, client, authorization server và resource server; access token đại diện cho quyền truy cập có scope và thời hạn. (rfc-editor.org) OWASP Top 10 hiện có bản 2025; trong đó Broken Access Control, Security Misconfiguration, Injection, Insecure Design và Authentication Failures là các nhóm rủi ro quan trọng cần đưa vào review thiết kế. (top10.owasp.org)

### **Cần hiểu đến mức nào**

Không chỉ hỏi:

`“API có JWT chưa?”`

Mà phải hỏi:

`- Token do ai phát hành?
- API verify signature, issuer, audience, expiry thế nào?
- Scope nào cho API nào?
- Token bị lộ thì blast radius là gì?
- Refresh token lưu ở đâu?
- API có IDOR/Broken Access Control không?
- Rate limit và audit cho endpoint nhạy cảm chưa?`
