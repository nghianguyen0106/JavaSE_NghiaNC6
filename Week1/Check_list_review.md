# Check list review

## **SOLID**

- [ ]  Giải thích được 5 nguyên tắc.
- [ ]  Nhận diện được code smell.
- [ ]  Refactor được một service lớn.
- [ ]  Viết được unit test sau refactor.

## **Clean Architecture**

- [ ]  Vẽ được các layer.
- [ ]  Giải thích được Dependency Rule.
- [ ]  Domain không phụ thuộc framework.
- [ ]  Controller không chứa business logic.

## **Hexagonal Architecture**

- [ ]  Hiểu primary adapter.
- [ ]  Hiểu secondary adapter.
- [ ]  Tạo được input port.
- [ ]  Tạo được output port.
- [ ]  Thay được adapter mà không sửa use case.

## **DDD**

- [ ]  Phân biệt Entity và Value Object.
- [ ]  Xác định được Aggregate Root.
- [ ]  Đặt business rule trong domain.
- [ ]  Viết test cho invariant.

## **CQRS/Event Sourcing**

- [ ]  Phân biệt command và query.
- [ ]  Phân biệt command và event.
- [ ]  Nêu được ưu/nhược điểm.
- [ ]  Biết khi nào không nên dùng.

## **Saga/Circuit Breaker**

- [ ]  Vẽ được distributed flow.
- [ ]  Xác định được compensation.
- [ ]  Hiểu choreography và orchestration.
- [ ]  Hiểu Closed/Open/Half-open.
- [ ]  Phân biệt retry và circuit breaker.
